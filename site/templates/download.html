Linux and macOS, from a terminal

$ curl -fsSL https://binbun.org/install.sh | sh
The script is open to read, and checks every download against the release's checksums.

As libraries

Python, with the whole engine:

$ pip install binbun

Rust, the engine: load, analyse and decompile a binary. binbun-session adds what the app and Python use on top: background analysis, projects and undoable edits.

$ cargo add binbun$ cargo add binbun-session

Rust, the decoders on their own: binbun-disasm for both architectures, one API, or one architecture's crate with all its detail:

$ cargo add binbun-disasm$ cargo add binbun-x86$ cargo add binbun-aarch64

C and C++: libbinbun with its headers, in every release.
