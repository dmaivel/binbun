# Linux system calls syzkaller's descriptions leave out (calls that block,
# change the fuzzer's own process, or that it does not fuzz), read with
# its sys.txt (whose fd, pid and timespec these use), so that every call a
# program makes has the arguments the kernel reads: without a
# description, decompilation takes a call to read all six argument
# registers. Each takes the parameters of its SYSCALL_DEFINEn on x86-64,
# in order, with types no finer than its prototype's; calls the kernel
# no longer implements (sys_ni_syscall) are left out.
#
# futex's arguments depend on its operation; decompilation counts them
# from a constant one (binbun-decompile's lowering of system calls).
